# Идентификация Пользователей и Противодействие Отмыванию Денег (KYC-AML Compliance 115-FZ)

Документ описывает систему соблюдения Федерального закона № 115-ФЗ «О противодействии легализации (отмыванию) доходов, полученных преступным путем, и финансированию терроризма».

---

## 1. Уровни идентификации пользователей

| Уровень (Tier) | Требуемые данные | Лимиты операций | Процедура проверки |
| :--- | :--- | :--- | :--- |
| **Tier 0 (Гость / Просмотр)** | Telegram ID | Только просмотр каталога | Авторизация через Telegram |
| **Tier 1 (Упрощенная идентификация)** | Подтвержденный телефон + ИНН физлица | Вывод до 15 000 ₽ за операцию / до 40 000 ₽ в месяц | Автоматическая сверка ИНН по базе ФНС (API) |
| **Tier 2 (Самозанятый НПД)** | ИНН + статус плательщика НПД + номер СБП | Вывод до 100 000 ₽ в сутки / до 2 400 000 ₽ в год | Интеграция с сервисом «Мой налог» |
| **Tier 3 (Корпоративный / B2B)** | Карточка организации, ОГРН, выписка из ЕГРЮЛ, банковские реквизиты | Без лимитов (безналичный расчет) | Проверка по базам СПАРК / Контур.Фокус, ЭДО |

---

## 2. AML-мониторинг и стоп-факторы

Платформа блокирует финансовые операции и передает сведения в банк-эквайер при выявлении следующих признаков подозрительных операций:
1. Зачисление крупной суммы рекламодателем с последующим немедленным запросом возврата без запуска кампаний (признак попытки транзита или обналичивания).
2. Вывод средств на счета третьих лиц, чьи данные не совпадают с подтвержденным ИНН пользователя.
3. Совпадение данных пользователя с перечнем экстремистов и террористов Росфинмониторинга (проверка по публичному реестру).
