## 2. Официальная документация API социальных сетей

| Платформа | API / Endpoint | Документация | Статус доступности и лимиты |
| :--- | :--- | :--- | :--- |
| **YouTube Data API v3** | `videos.list` (`part=statistics,snippet`) | [Google Developers: YouTube Data API](https://developers.google.com/youtube/v3/docs/videos/list) | **Доступно официально.** Требуется API Key (без OAuth для публичных видео). Квота: 1 единица за вызов (до 50 video ID в пачке). Базовая бесплатная квота — 10 000 единиц/день. |
| **VK API** | `video.get`, `wall.getById` | [VK Developers: video.get](https://dev.vk.com/method/video.get) | **Доступно официально.** Сервисный ключ приложения (Service Access Token). До 20 запросов в секунду. Возвращает `views`, `likes`. |
| **TikTok API** | Display API / Commercial Content API / Research API | [TikTok for Developers](https://developers.tiktok.com/) | **Ограничено.** Public Display API требует авторизации пользователя (OAuth 2.0). Произвольные публичные ссылки без авторизации владельца через официальный API не отдают точную динамику просмотров. Требуется гибридный подход (OAuth + скрапинг/oEmbed). |
| **Instagram Graph API** | `/{media-id}/insights` | [Meta for Developers: Instagram Graph API](https://developers.facebook.com/docs/instagram-api) | **Строго ограничено.** Статистика доступна ТОЛЬКО для авторизованных бизнес/креатор аккаунтов, привязанных к Facebook Page. Статистика произвольных чужих Reels через Graph API официально **недоступна**. |

## 3. Законодательство и нормативная база РФ

| Нормативный акт | Статья / Положение | Значение для платформы |
| :--- | :--- | :--- |
| **ФЗ № 347-ФЗ (поправки к ФЗ «О рекламе» № 38-ФЗ)** | Статья 18.1 «Единый реестр интернет-рекламы» (ЕРИР) | Обязательная маркировка всей интернет-рекламы в РФ (получение токена `erid` через ОРД, передача актов и разаллокаций). Платформа обязана автоматизировать взаимодействие с ОРД (ОРД-А, ОРД VK или ОРД Яндекс). |
| **КоАП РФ Статья 14.3 (части 15–17)** | Штрафы за отсутствие маркировки рекламы (с 01.09.2023) | Штрафы для физлиц до 100 000 ₽, для юрлиц до 500 000 ₽ за каждый незамаркированный креатив. Критично для правил публикации роликов клипперами. |
| **ФЗ № 422-ФЗ (Налог на профессиональный доход)** | Налог для самозанятых (НПД) | Легальная база выплат клипперам: 6% налог при выплатах от юрлиц. Автоматическая проверка статуса через ФНС API и формирование чеков. |
| **ГК РФ Часть 4 (Интеллектуальная собственность)** | Статьи 1229, 1270, 1274 (Свободное использование) | Лицензирование исходных материалов рекламодателя (простая неисключительная лицензия на переработку и публикацию клипперами). Защита авторов от претензий по DMCA / ст. 1252 ГК РФ. |
| **ФЗ № 152-ФЗ «О персональных данных»** | Хранение данных граждан РФ на серверах в РФ | Обязательное размещение БД пользователей на серверах в РФ (Selectel, Yandex Cloud) с соблюдением требований локализации. |
| **ФЗ № 161-ФЗ «О национальной платежной системе»** | Переводы без открытия счета, номинальные счета | Использование лицензированных платежных агрегаторов (ЮKassa, Продамус, Т-Бизнес) для эскроу и выплат, исключающее необходимость банковской лицензии для платформы. |

## 5. Методология классификации утверждений в документации

В рамках всей проектной документации принята строгая классификация информации:
1. `[ФАКТ]` — проверенное знание, подкрепленное официальной документацией, законодательством или действующими тарифами API.
2. `[ГИПОТЕЗА / ПРЕДПОЛОЖЕНИЕ]` — расчетные метрики, бизнес-предположения (например, средняя конверсия, средний чек, готовность клипперов работать за определенный CPM), требующие полевой валидации.
3. `[РЕКОМЕНДАЦИЯ]` — инженерное или продуктовое решение, выработанное на базе лучших практик индустрии (например, выбор модульного монолита, использование очередей BullMQ, Telegram Mini App).
4. `[ТРЕБУЕТ СОГЛАСОВАНИЯ]` — критические развилки для основателя проекта (например, юридическая форма компании, размер базовой комиссии, правила арбитража).
5. `[ОТКРЫТЫЙ ВОПРОС]` — технические или юридические неопределенности, находящиеся на этапе исследования.
