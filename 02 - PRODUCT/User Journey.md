# Путь Пользователя-Клиппера (User Journey Map)

Документ описывает эмоциональное и функциональное состояние клиппера на каждом этапе взаимодействия с платформой Konveer.

---

## Карта пути клиппера (User Journey Stages)

```mermaid
journey
    title Путь начинающего клиппера на платформе Konveer
    section 1. Знакомство
      Увидел видео о заработке на нарезках: 4: TikTok / Telegram
      Перешел в бота @KonveerBot: 5: Telegram
      Открыл Mini App в 1 клик: 5: TMA
    section 2. Выбор задания
      Изучил каталог с фильтрами по ставкам: 4: Каталог
      Выбрал кампанию любимого стримера: 5: Карточка
      Скачал хайлайты стрима: 4: S3 Ссылка
    section 3. Создание и сдача
      Смонтировал ролик в CapCut: 4: CapCut
      Опубликовал в Shorts: 4: YouTube
      Вставил ссылку в бот: 5: Форма сдачи
    section 4. Просмотры и доход
      Ролик попал в рекомендации: 5: Алгоритмы YouTube
      Начисление баланса в холд: 4: Баланс PENDING
      Таймер 72ч истек, деньги разморожены: 5: Баланс AVAILABLE
    section 5. Выплата
      Ввел телефон и банк СБП: 5: Экран вывода
      Получил деньги на карту через 10 секунд: 5: СБП, Push
```
