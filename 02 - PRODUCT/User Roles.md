# Пользовательские Роли в Системе (User Roles)

Документ описывает все системные роли пользователей платформы Konveer, их назначение и жизненный цикл.

---

## 1. Иерархия ролей платформы

1. **GUEST (Неавторизованный пользователь)**:
   - Доступ: Просмотр лендинга, публичного каталога активных кампаний, справки и юридических документов.
2. **CLIPPER (Создатель контента / Монтажер)**:
   - Доступ: Telegram Mini App, каталог заданий, скачивание исходников, отправка ссылок на ролики, личный баланс, рейтинг, достижения, вывод средств через СБП.
3. **ADVERTISER (Рекламодатель / Заказчик)**:
   - Доступ: Десктопный Web Dashboard, создание и финансирование кампаний, загрузка медиаисходников, аналитика просмотров, управление бюджетами, закрывающие документы.
4. **MODERATOR (Сотрудник службы поддержки и модерации)**:
   - Доступ: Очередь ручной проверки роликов, рассмотрение апелляций клипперов, проверка жалоб рекламодателей, выдача страйков.
5. **FIN_ADMIN (Финансовый контролер / Бухгалтер)**:
   - Доступ: Просмотр финансового Ledger, сверка банковских выписок, подтверждение крупных выплат, выставление B2B счетов.
6. **SUPER_ADMIN (Технический директор / Владелец)**:
   - Доступ: Полный неограниченный доступ ко всем параметрам системы, системным настройкам, назначению ролей сотрудников и аудиту.
