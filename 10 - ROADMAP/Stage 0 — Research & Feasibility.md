# 🔬 Stage 0 — Research & Feasibility (Исследования и выполнимость)

## 1. Паспорт этапа
* **Цель этапа:** Полномасштабное проектирование продуктовой, технической, финансовой и правовой модели проекта до написания первой строчки прикладного кода.
* **Приоритет:** Критический (`CRITICAL`).
* **Ориентировочная длительность:** 2 недели (Текущий этап).
* **Зависимости:** Нет.

---

## 2. Перечень ключевых задач
- [x] Анализ глобального опыта (Whop Content Rewards, Clipster, OpenClip).
- [x] Аудит возможностей и лимитов API соцсетей (YouTube Data API v3, VK API, TikTok, Meta).
- [x] Разработка математической модели неизменяемого Ledger двойной бухгалтерской записи.
- [x] Анализ правовой среды РФ (347-ФЗ о рекламе, ЕРИР, ОРД, 422-ФЗ о самозанятых, 152-ФЗ о персональных данных).
- [x] Формирование полного PRD, матрицы ролевого доступа и сценариев CJM.
- [x] Формирование базы знаний Obsidian с перекрестной линковкой.

---

## 3. Критерии выхода с этапа (Exit Gate Criteria)
1. Все 12 разделов Obsidian Vault полностью заполнены и не содержат плейсхолдеров.
2. Подтверждена техническая возможность бесплатного сбора просмотров YouTube Shorts и VK Клипов без OAuth владельца.
3. Согласована базовая финансовая модель (20% Take Rate) и расчет точки безубыточности.
