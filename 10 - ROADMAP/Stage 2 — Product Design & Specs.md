# 🎨 Stage 2 — Product Design & Specs (Проектирование и макеты)

## 1. Паспорт этапа
* **Цель этапа:** Создание высокоточных UI-макетов в Figma, интерактивных прототипов TMA и Web, финализация OpenAPI спецификаций до старта кодинга.
* **Приоритет:** Высокий (`HIGH`).
* **Ориентировочная длительность:** 2 недели.
* **Зависимости:** Успешное завершение Stage 1 (ручная валидация подтвердила паттерны).

---

## 2. Перечень ключевых задач
- [ ] Отрисовка Figma UI Kit (компоненты, токены, Dark/Light палитры).
- [ ] Отрисовка всех экранов Telegram Mini App для клиппера (Feed, Detail, Submit Sheet, Wallet).
- [ ] Отрисовка десктопных макетов кабинета рекламодателя (Dashboard, Wizard запуска, Аналитика).
- [ ] Сборка кликабельного прототипа в Figma для мобильного тестирования с реальными клипперами.
- [ ] Написание OpenAPI / Swagger спецификации для всех эндпоинтов бэкенда.
- [ ] Финальная ревизия схемы БД `schema.prisma`.

---

## 3. Критерии выхода с этапа (Exit Gate Criteria)
1. Кликабельный прототип протестирован на 5 клипперах (время сдачи тестовой ссылки $< 30$ секунд).
2. Спецификация API полностью согласована между frontend и backend разработчиками.
