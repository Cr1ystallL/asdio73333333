# 💻 Stage 3 — MVP Development (Разработка первой версии)

## 1. Паспорт этапа
* **Цель этапа:** Программная реализация ядра платформы (монолит NestJS, TMA на Next.js, Web-кабинет, интеграция YouTube Data API v3, VK API, PostgreSQL Ledger).
* **Приоритет:** Критический (`CRITICAL`).
* **Ориентировочная длительность:** 7–8 недель.
* **Зависимости:** Утвержденные спецификации Stage 2.

---

## 2. Ключевые спринты разработки

### Спринт 1–2: Инфраструктура, БД и Аутентификация
* Развертывание Docker-окружения, PostgreSQL 16, Redis 7.
* Инициализация миграций Prisma (таблицы `users`, `wallets`, `ledger_entries`).
* Авторизация через `Telegram.WebApp.initData` на бэкенде.
* JWT сессии, RBAC гарды.

### Спринт 3–4: Кампании, Сабмиты и Интеграция API
* Модуль создания кампаний (загрузка ТЗ, лимиты, эскроу-блокировка).
* Модуль сабмитов (нормализация URL, валидация кода `#clip_USERID`).
* Интеграция с `YouTube Data API v3` (пакетный сбор статистики по 50 видео).
* Интеграция с `VK API` (`video.get`).
* Реализация очередей BullMQ для фонового опроса каждые 6 часов.

### Спринт 5–6: Финансовый Ledger и Антифрод
* Реализация двойной записи Ledger (атомарные транзакции `SERIALIZABLE`).
* Модуль скоринга рисков (ER, velocity spike, pHash).
* Холд-механика на 72 часа и автоперевод в `AVAILABLE`.

### Спринт 7–8: Фронтенд TMA, Web-кабинет и Админка
* Верстка Telegram Mini App (каталог, карточка, модалка сдачи ссылки, кошелек).
* Верстка Web-кабинета рекламодателя (дашборд, визард кампании, таблица видео).
* Административная панель для модератора.

---

## 3. Критерии выхода с этапа (Exit Gate Criteria)
1. Unit-тесты финансового Ledger покрывают 100% сценариев движения средств.
2. Сквозной интеграционный тест (E2E): Создание кампании $\rightarrow$ Сабмит ролика YouTube $\rightarrow$ Авто-опрос просмотров $\rightarrow$ Переход в холд $\rightarrow$ Начисление баланса.
3. Развернут стабильный Staging-сервер в Selectel.
