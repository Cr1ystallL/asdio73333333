# Провайдеры Облачного Хранилища S3 (S3 Storage Providers)

Документ описывает выбор и архитектуру интеграции с S3-совместимым объектным хранилищем для исходных медиаматериалов кампаний (стримы, хайлайты, брендпаки, логотипы, шрифты, аудиодорожки) и документов.

---

## 1. Детальный аудит интеграции по 12 критериям

### 1. Возможности (Capabilities)
- Хранение терабайтов исходного видео высокого разрешения (1080p, 4K ProRes/MP4).
- Выдача временных подписанных ссылок (Pre-signed URLs) для прямой безопасной загрузки рекламодателем без проксирования через бэкенд (`Direct-to-S3 Upload`).
- Быстрая раздача клипперам через CDN (Content Delivery Network) с точками присутствия по всей РФ.

### 2. Ограничения (Limitations)
- Трафик на скачивание (egress traffic) тарифицируется отдельно у большинства облачных провайдеров.
- Время жизни временных ссылок на скачивание ограничивается политикой безопасности (от 1 до 6 часов).

### 3. Авторизация (Authorization)
- Стандартный протокол AWS S3 Signature v4: `Access Key ID` + `Secret Access Key`.

### 4. Необходимые разрешения (Required Scopes)
- Права на чтение/запись в выделенные бакеты: `konveer-media-raw` (исходники), `konveer-public-assets` (логотипы, аватары), `konveer-legal-docs` (акты, чеки).

### 5. Доступность статистики (Stats Availability)
- Детальные метрики через Prometheus / Cloud Monitoring: объем хранения, количество операций `GET/PUT`, исходящий трафик.

### 6. Возможность разграничения доступа (Access Control)
- Приватные бакеты с доступом строго по Pre-signed URLs. Исходники конкретной кампании доступны только клипперам, принявшим участие в этой кампании.

### 7. Возможность загрузки больших файлов (Multipart Upload)
- Полная поддержка `Multipart Upload` для файлов размером до 5 ТБ (типичные многочасовые стримы 5–20 ГБ).

### 8. Rate limits
- До 3 500 запросов `PUT` и до 5 500 запросов `GET` в секунду на каждый префикс бакета.

### 9. Стоимость (Pricing)
- **Selectel / VK Cloud**:
  - Хранение: ~1.5 – 2.0 ₽ за 1 ГБ в месяц.
  - Исходящий трафик (CDN): ~0.8 – 1.2 ₽ за 1 ГБ.
  - Пример: 1 ТБ видеоисходников обходится в ~2 000 ₽ / месяц.

### 10. Юридические ограничения (Legal Restrictions)
- 152-ФЗ и 242-ФЗ: дата-центры провайдера обязаны физически находиться на территории РФ (Москва, Санкт-Петербург, Екатеринбург). Использование зарубежного AWS S3 юридически запрещено для хранения персональных данных и документов резидентов РФ.

### 11. Риски (Risks)
- Неконтролируемый рост расходов на CDN при массовом скачивании клипперами тяжелых видео (митигируется сжатием превью на лету и хранением предварительно нарезанных 1–2 минутных хайлайтов).

### 12. Альтернативные варианты (Alternatives)
- Выбор сделан в пользу **Selectel Object Storage** (или **VK Cloud**) как наиболее стабильных и надежных российских платформ с гарантированным соответствием 152-ФЗ (УЗ-1).
