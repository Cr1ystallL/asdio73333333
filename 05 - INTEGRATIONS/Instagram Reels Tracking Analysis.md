# 📸 Анализ ограничений отслеживания Instagram Reels

## 1. Официальные ограничения Meta Graph API

Meta (Instagram) проводит самую жесткую политику закрытости данных среди всех социальных сетей:
1. **Только собственные медиа через OAuth:** Официальный эндпоинт `GET /{ig-media-id}/insights` возвращает охваты, просмотры и взаимодействия **ТОЛЬКО** в том случае, если владелец профиля (тип Business или Creator) авторизовался в приложении через Facebook Login и предоставил права `instagram_manage_insights`.
2. **Невозможность проверки чужого видео:** Через официальный API технически невозможно передать публичный URL чужого Reels (`instagram.com/reel/C8x...`) и получить количество просмотров.
3. **Статус Meta в РФ:** Деятельность Meta признана экстремистской на территории РФ. Официальное подключение корпоративного API российскими юрлицами юридически токсично.

---

## 2. Стратегическое решение по Instagram Reels
* **В первой версии (MVP) Instagram Reels полностью исключен из списка автоматических кампаний.**
* На этапе масштабирования (Stage 6) поддержка Reels реализуется исключительно в формате **ручных баунти-конкурсов** (клипперы отправляют ссылки, а финалисты подтверждают просмотры скринкастом экрана приложения) либо для зарубежного юридического лица платформы через официальный OAuth.
