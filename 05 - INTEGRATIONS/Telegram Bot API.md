# Интеграция с Telegram Bot API и Mini Apps (Telegram Bot API)

Документ описывает архитектуру интеграции с Telegram: авторизацию через Telegram Mini App (TMA), работу официального бота `@KonveerBot`, доставку системных уведомлений и бесшовный пользовательский опыт для клипперов.

---

## 1. Детальный аудит интеграции по 12 критериям

### 1. Возможности (Capabilities)
- Бесшовная авторизация клиппера через криптографическую валидацию `Telegram.WebApp.initData`.
- Запуск полноэкранного React/Next.js веб-приложения внутри Telegram (TMA).
- Отправка мгновенных транзакционных Push-уведомлений: одобрение ролика, фиксация просмотров, начисление вознаграждения, статус выплаты.
- Прием ссылок на опубликованные ролики прямо в диалоге с ботом (альтернатива интерфейсу Mini App).

### 2. Ограничения (Limitations)
- Ограничение на размер отсылаемых файлов через бота: до 50 МБ для скачивания через стандартный Bot API (для исходников видео большего размера клиппер перенаправляется на S3-ссылку).
- Запрет на спам и несанкционированные массовые рассылки (сообщение отправляется только пользователю, который предварительно нажал `/start`).

### 3. Авторизация (Authorization)
- **HMAC-SHA-256 валидация `initData`**:
  Хэш вычисляется бэкендом с использованием секретного ключа бота:
  $$\text{secret\_key} = \text{HMAC-SHA256}(\text{bot\_token}, \text{"WebAppData"})$$
  $$\text{calculated\_hash} = \text{HMAC-SHA256}(\text{data\_check\_string}, \text{secret\_key})$$
  Если `calculated_hash === initData.hash` и дата `auth_date` не старше 24 часов, пользователь признается авторизованным без логинов и паролей.

### 4. Необходимые разрешения (Required Scopes)
- Доступ к Telegram ID, имени пользователя (`username`), имени и фамилии.

### 5. Доступность статистики (Stats Availability)
- Telegram Bot API предоставляет полную информацию о доставке сообщений (`MessageId`, `chat_id`).

### 6. Возможность проверки пользователя (User Verification)
- 100% защита от подделки: Telegram ID гарантирован криптографической подписью серверов Telegram.

### 7. Возможность получения статуса доставки
- Мгновенный HTTP-ответ сервера Telegram при вызове `sendMessage`.

### 8. Rate limits
- До 30 сообщений в секунду для разных пользователей.
- Не более 1 сообщения в секунду одному и тому же пользователю (для очередей рассылок используется BullMQ с rate limiter).

### 9. Стоимость (Pricing)
- Полностью бесплатно.

### 10. Юридические ограничения (Legal Restrictions)
- Персональные данные Telegram ID хранятся в БД на территории РФ (152-ФЗ).
- Telegram официально разрешен и широко используется бизнесом и государственными органами в РФ.

### 11. Риски (Risks)
- Риск блокировки бота пользователем (`Bot was blocked by the user` — ошибка 403). Обрабатывается бэкендом: статус пользователя переводится в `notifications_disabled = true`, попытки отправки прекращаются.

### 12. Альтернативные варианты (Alternatives)
- Отдельное мобильное приложение под iOS/Android (отклонено для MVP: огромные затраты на разработку, риск санкционных блокировок в App Store / Google Play). Telegram Mini App обеспечивает 100% охват целевой аудитории с нулевым барьером входа.
