# Интеграция с VK API для VK Клипов (VK API)

Документ описывает интеграцию с российской платформой **ВКонтакте (VK API)** для отслеживания просмотров в вертикальных видео «VK Клипы».

---

## 1. Детальный аудит интеграции по 12 критериям

### 1. Возможности (Capabilities)
- Эндпоинты `video.get` и `wall.get` позволяют получать информацию о видеоклипах: количество просмотров (`views`), лайки (`likes.count`), репосты (`reposts.count`), комментарии (`comments.count`), описание, дата публикации, владелец (`owner_id`).
- Поддержка VK Mini Apps (прямой запуск веб-интерфейса клиппера внутри супер-аппа VK при необходимости).

### 2. Ограничения (Limitations)
- Приватные страницы или закрытые сообщества не отдают статистику через сервисный токен. Видеоклип обязан быть опубликован в открытом доступе (`privacy_view = 0`).
- Статистика просмотров может кэшироваться на CDN ВКонтакте с задержкой 5–15 минут.

### 3. Авторизация (Authorization)
- **Сервисный ключ доступа (Service Access Token)**: создается в кабинете разработчика VK Developers. Не требует согласия конечных пользователей для чтения открытых видео.

### 4. Необходимые разрешения (Required Scopes)
- Для публичного чтения через сервисный ключ scopes не требуются (базовый доступ к публичному контенту).

### 5. Доступность статистики (Stats Availability)
- **Доступно официально и публично**: просмотры и реакции публичных VK Клипов доступны без ограничений.

### 6. Возможность проверки владельца публикации (Ownership Verification)
- Проверка через размещение проверочного хештега в описании клипа (`#konveer_id`) либо через VK ID клиппера при авторизации через VK ID SDK.

### 7. Возможность получения количества просмотров (Views Retrieval)
- Полностью доступно через параметр `views` в ответе метода `video.get?videos=owner_id_video_id`.

### 8. Rate limits
- Сервисный ключ VK API позволяет совершать **до 20–50 запросов в секунду** (в зависимости от категории приложения).
- Эндпоинт `execute` позволяет паковать до 25 вызовов API в один сетевой HTTP-запрос, что дает до **1 250 проверок видео в секунду**.

### 9. Стоимость (Pricing)
- Полностью бесплатно.

### 10. Юридические ограничения (Legal Restrictions)
- Полное соответствие законодательству РФ (152-ФЗ, сервера ВКонтакте находятся в РФ). ВКонтакте официально аккредитован Минцифры РФ, является опорной национальной платформой.

### 11. Риски (Risks)
- Риск накруток через сервисы дешевого буксового трафика (митигируется проверкой соотношения лайков к просмотрам $ER$ и 72-часовым холдом).

### 12. Альтернативные варианты (Alternatives)
- Официальный VK API является единственным и самым стабильным инструментом для VK Клипов.

## 2. Формат вызова и архитектура батчинга

```typescript
// Пример выполнения пакетного запроса через VK API execute
const code = `
  var vids = "${videoIdsJoined}".split(",");
  var results = [];
  var i = 0;
  while (i < vids.length) {
    var v = API.video.get({ "videos": vids[i] });
    if (v.items.length > 0) {
      results.push({ "id": vids[i], "views": v.items[0].views, "likes": v.items[0].likes.count });
    }
    i = i + 1;
  }
  return results;
`;
```
