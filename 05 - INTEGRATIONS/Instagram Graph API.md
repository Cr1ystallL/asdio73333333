# Интеграция с Instagram Graph API (Instagram Graph API)

Документ описывает возможности, правовой статус и архитектуру работы с контентом Instagram Reels для платформы Konveer.

---

## 1. Детальный аудит интеграции по 12 критериям

### 1. Возможности (Capabilities)
- Instagram Graph API (часть Meta for Developers) предоставляет доступ к статистике роликов Instagram Reels: `plays` (воспроизведения), `reach` (охват), `likes` (лайки), `comments` (комментарии), `shares` (пересылки), `saved` (сохранения).

### 2. Ограничения (Limitations)
- **Фундаментальное ограничение API**: Instagram Graph API работает **только с Профессиональными аккаунтами (Professional / Creator / Business)**, привязанными к странице Facebook. Личные (Personal) аккаунты вообще не поддерживаются API.
- Получение статистики по публичной ссылке чужого ролика через официальный API **невозможно в принципе**.
- Требуется OAuth 2.0 авторизация автора через Facebook Login.

### 3. Авторизация (Authorization)
- Facebook Login for Business с генерацией долгоживущего токена (User Access Token $\to$ Page Access Token $\to$ IG User ID).

### 4. Необходимые разрешения (Required Scopes)
- `instagram_basic`, `instagram_manage_insights`, `pages_show_list`, `pages_read_engagement`.

### 5. Доступность статистики (Stats Availability)
- Только для авторизованного владельца Creator/Business аккаунта.

### 6. Возможность проверки владельца публикации (Ownership Verification)
- 100% подтверждение при прохождении OAuth-флоу.

### 7. Возможность получения количества просмотров (Views Retrieval)
- Метрика `plays` и `reach` доступна через эндпоинт `/{ig-media-id}/insights?metric=plays,total_interactions`.

### 8. Rate limits
- 200 вызовов в час на одного пользователя в рамках бизнес-приложения Meta.

### 9. Стоимость (Pricing)
- Бесплатно для разработчиков.

### 10. Юридические ограничения в РФ (КРИТИЧЕСКИ ВАЖНО)
- **Правовой статус Meta в РФ**: Решением Тверского районного суда г. Москвы от 21.03.2022 компания Meta Platforms Inc. признана **экстремистской организацией**, ее деятельность на территории РФ запрещена.
- **Ограничения для юридического лица платформы (ООО в РФ)**:
  - Запрещено переводить любые денежные средства Meta (покупка рекламы, подписок) — это квалифицируется как финансирование экстремистской деятельности (ст. 282.3 УК РФ).
  - Запрещено публично демонстрировать логотипы Meta, Facebook и Instagram без обязательного предупреждения или маркировки (ст. 20.3 КоАП РФ).
  - Использование API само по себе (без финансовых расчетов с Meta) прямо не запрещено, однако несет повышенное регуляторное внимание Роскомнадзора и прокуратуры.

### 11. Риски (Risks)
- Риск блокировки российских IP-адресов серверов со стороны Meta.
- Необходимость VPN для конечных пользователей в РФ для просмотра роликов.
- Сложность привязки (90% клипперов не имеют Creator-аккаунта с привязкой к Facebook).

### 12. Альтернативные варианты (Решение команды)
- **Решение для MVP**: Полное исключение Instagram Reels из автоматического скоринга первого релиза в РФ.
- **Для B2B-кампаний**: Ручная модерация по предоставленному клиппером скриншоту/записи экрана кабинета Instagram Insights с проверкой уникального промокода в шапке профиля или ролике.
