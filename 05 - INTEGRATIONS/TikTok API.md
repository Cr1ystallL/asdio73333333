# Интеграция с TikTok API (TikTok API)

Документ описывает техническую и юридическую осуществимость интеграции с **TikTok API** для платформы Konveer на территории РФ и СНГ.

---

## 1. Детальный аудит интеграции по 12 критериям

### 1. Возможности (Capabilities)
- TikTok for Developers (Research API / Display API / Content Posting API).
- Позволяет получать профиль пользователя, список видео и базовую статистику видео (просмотры, лайки, шеринги).

### 2. Ограничения (Limitations)
- **Критическое региональное ограничение в РФ**: с марта 2022 года TikTok официально приостановил публикацию нового контента и прямые эфиры для пользователей из России.
- Большинство российских пользователей и клипперов используют модифицированные клиенты TikTok (TikTok Mod / Scarlet / SideStore) либо иностранные eSIM для обхода ограничений.
- Публичный официальный TikTok API не позволяет получать просмотры произвольного ролика по ссылке без OAuth-авторизации автора (в отличие от YouTube Data API).

### 3. Авторизация (Authorization)
- Требуется TikTok Login Kit (OAuth 2.0).

### 4. Необходимые разрешения (Required Scopes)
- `user.info.basic`, `video.list`.

### 5. Доступность статистики (Stats Availability)
- Доступна только для авторизованных авторов через Display API.
- TikTok Research API (где есть данные по произвольным роликам) доступен **исключительно аккредитованным академическим институтам и исследователям в США и ЕС**, коммерческим компаниям доступ закрыт.

### 6. Возможность проверки владельца публикации (Ownership Verification)
- Через Login Kit подтверждается со 100% точностью.

### 7. Возможность получения количества просмотров (Views Retrieval)
- Официально доступно только для авторизованного автора. По чужой ссылке через публичный API просмотры не отдаются.

### 8. Rate limits
- 10 000 вызовов в минуту для одобренных приложений.

### 9. Стоимость (Pricing)
- Бесплатно для разработчиков при одобрении корпоративного аккаунта.

### 10. Юридические ограничения (Legal Restrictions)
- ByteDance предъявляет жесткие требования к политике конфиденциальности, запрещает передачу пользовательских данных третьим лицам без явного согласия. В РФ статус сервиса официально ограничен в связи с локализацией данных (242-ФЗ).

### 11. Риски (Risks)
- **Риск неодобрения приложения**: TikTok Developers отклоняет коммерческие стартапы из РФ без юридического присутствия в нейтральных юрисдикциях (ОАЭ, Казахстан, Кипр).
- **Риск блокировок прокси при скрапинге**: попытки парсить веб-версию `tiktok.com/@user/video/...` наталкиваются на агрессивную антибот-защиту Akamai / Kasada.

### 12. Альтернативные варианты (Решение команды)
- **MVP (Stage 3)**: TikTok исключен из полностью автоматического трекинга по ссылке.
- **Stage 4 (Closed Beta)**: Внедрение **полуавтоматической верификации**:
  1. Клиппер присылает ссылку на видео + экранную видеозапись/скриншот из вкладки «Аналитика» приложения TikTok.
  2. В описании видео клиппер обязан разместить уникальный проверочный промокод кампании.
  3. Модератор подтверждает просмотры вручную за 2 клика в админ-панели (при бюджетах от 10 000 ₽).
- **Stage 6 (Scale)**: Подключение официального TikTok Commercial API через юридическое лицо в ОАЭ или Казахстане.
