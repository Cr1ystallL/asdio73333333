# Анализ YouTube Analytics API (YouTube Analytics API)

Документ содержит углубленный сравнительный анализ применимости **YouTube Analytics API** в сравнении с **YouTube Data API v3** для задач платформы Konveer.

---

## 1. Сравнительный аудит по 12 критериям

### 1. Возможности (Capabilities)
- Предоставляет глубокие аналитические отчеты: демография аудитории (страны, города, возраст, пол), источники трафика (лента Shorts, поиск, рекомендации, внешние сайты), удержание аудитории (Audience Retention по секундам), среднее время просмотра (Average View Duration).

### 2. Ограничения (Limitations)
- **Фундаментальное ограничение**: YouTube Analytics API работает **исключительно через Google OAuth 2.0 от имени владельца канала**.
- Невозможно запросить аналитику чужого канала или ролика без выдачи полных прав доступа владельцем канала.
- Задержка обновления данных (Reporting Lag): отчеты Analytics API формируются с задержкой в 24–48 часов по сравнению с реальным временем.

### 3. Авторизация (Authorization)
- Требуется полный трехсторонний OAuth 2.0 пользовательский флоу: редирект на аккаунты Google, экран согласия (Consent Screen), получение Access Token и Refresh Token.

### 4. Необходимые разрешения (Required Scopes)
- `https://www.googleapis.com/auth/yt-analytics.readonly`
- `https://www.googleapis.com/auth/youtube.readonly`

### 5. Доступность статистики (Stats Availability)
- Доступна только для каналов, которые явно авторизовались в системе через Google Sign-In.

### 6. Возможность проверки владельца публикации (Ownership Verification)
- 100% достоверность: поскольку клиппер авторизуется через свой Google-аккаунт, подделка владения каналом абсолютно невозможна.

### 7. Возможность получения количества просмотров (Views Retrieval)
- Доступно, но обновляется медленнее (раз в сутки в агрегированных таблицах), чем через Data API (где просмотры видны почти в реальном времени).

### 8. Rate limits
- Запросы на отчеты Analytics тарифицируются отдельно и имеют строгие квоты на число параллельных репортов (до 100 одновременных запросов от проекта).

### 9. Стоимость (Pricing)
- Бесплатно в рамках квот Google Cloud.

### 10. Юридические ограничения (Legal Restrictions)
- Прохождение верификации приложения Google (Google App Verification / Security Assessment). Любое приложение, запрашивающее доступ к приватным данным YouTube, обязано пройти аудит Google, предоставить Privacy Policy, видеозапись флоу и юридическое подтверждение компании. Срок прохождения верификации: от 4 до 8 недель.

### 11. Риски (Risks)
- **Конверсионный барьер для клипперов**: подавляющее большинство начинающих клипперов (подростки, студенты, начинающие монтажеры) боятся связывать свой личный Google-аккаунт с незнакомой платформой из-за страха угона канала или утечки данных. Это снижает конверсию в онбординг на 60–75%.

### 12. Альтернативные варианты (Решение команды)
- **Архитектурное решение**:
  - **Для MVP и базовых кампаний**: использовать **YouTube Data API v3** (проверка по публичной ссылке без OAuth).
  - **Для премиальных B2B-кампаний (Stage 6)**: опциональное подключение OAuth через Analytics API для получения бейджа «Верифицированный автор» и доступа к бюджетам с высокими ставками (где рекламодателю критически важна география РФ и глубина удержания).

## 2. Сравнительная таблица Data API vs Analytics API

| Критерий | YouTube Data API v3 | YouTube Analytics API | Выбор платформы |
| :--- | :--- | :--- | :--- |
| **Авторизация автора** | Не требуется (любая ссылка) | Строго Google OAuth 2.0 | **Data API для старта** |
| **Барьер входа клиппера** | 0 секунд (вставил ссылку в бота) | 2–3 минуты (логин Google, права) | **Data API** |
| **Частота обновления** | Каждые 15–30 минут | Раз в 24–48 часов | **Data API** |
| **Глубина удержания (Retention)**| Нет | Да (% досмотра) | Analytics (в будущем) |
| **Гео-распределение (РФ %)** | Нет | Да (% просмотров из РФ) | Analytics (в будущем) |
| **Сложность запуска** | 1 день (получить API Key) | 2 месяца (верификация Google) | **Data API** |
