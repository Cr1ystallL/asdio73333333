# 👁️ Доступность интерфейса (Accessibility WCAG 2.1 AA)

## 1. Контрастность и читаемость
* Все текстовые пары (текст на темном фоне карточек `#161A20`) имеют коэффициент контрастности не менее **4.8:1** (превышает требования уровня AA).
* Числовые финансовые балансы (зеленый `#10B981` на темном фоне `#0D0F12`) имеют контрастность **8.1:1** (соответствует высшему стандарту AAA).

---

## 2. Мобильная сенсорная доступность (Touch Targets)
* Любая интерактивная область на смартфоне имеет физический размер не менее **44x44 CSS пикселей**.
* Расстояние между соседними кнопками не менее 8px для предотвращения случайных нажатий.

---

## 3. Семантика и Screen Readers (ARIA)
* Все иконки действий снабжены скрытыми подписями `aria-label` (например, `<button aria-label="Скопировать код автора">`).
* Динамически обновляемые счетчики просмотров и баланса имеют атрибут `aria-live="polite"`.
