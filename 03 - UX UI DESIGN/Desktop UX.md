# 🖥️ Десктопный UX и эргономика рабочих мест

## 1. Принципы десктопного интерфейса
* **Информационная плотность:** Десктопный интерфейс ориентирован на профессионалов (маркетологи, медиабайеры, финофицеры). Высокая плотность данных в таблицах (Compact Table View), быстрые фильтры без всплывающих окон.
* **Клавиатурные шорткаты:** Поддержка горячих клавиш в таблице модерации:
  * `[A]` — Одобрить выделенный ролик.
  * `[R]` — Отклонить с выбором причины.
  * `[Пробел]` — Воспроизвести превью видео в инлайн-плеере.
  * `[/]` — Фокус на поле глобального поиска.

---

## 2. Анатомия табличных представлений (Data Tables)
* Фиксированная шапка таблицы при вертикальном скролле (`Sticky Header`).
* Настройка видимости колонок (Column Visibility Toggle).
* Быстрый предпросмотр по клику (Drawer справа с деталями сабмита без перезагрузки страницы).
