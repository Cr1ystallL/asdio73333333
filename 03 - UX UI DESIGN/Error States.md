# ⚠️ Состояния ошибок и валидации (Error States)

## 1. Паттерны отображения ошибок

1. **Инлайн-ошибки полей форм (Inline Validation):**
   * Рамка инпута окрашивается в цвет `--status-danger` (`#EF4444`).
   * Под полем появляется текст ошибки 12px с иконкой предупреждения (например: *«Введите корректную ссылку на YouTube Shorts»*).
2. **Всплывающие уведомления (Toast Notifications):**
   * Появляются в верхней части экрана (в TMA) или в правом нижнем углу (в Web).
   * Автоматически исчезают через 4 секунды.
3. **Полноэкранные экраны сбоев (Full-page Error Fallback):**
   * Применяются при потере интернет-соединения или сбое сервера (HTTP 500).
   * Иллюстрация разрыва связи + крупная кнопка `[ Попробовать снова ]`.

## 2. Каталог текстов ошибок (Copywriting)

| Код ошибки | Пользовательский текст на русском языке | Рекомендованное действие |
| :--- | :--- | :--- |
| `ERR_SUBMIT_DUPLICATE` | *«Этот ролик уже добавлен в систему другим автором»* | Проверьте правильность вставленной ссылки |
| `ERR_CODE_NOT_FOUND` | *«В описании видео не найден проверочный код #clip_XXXXX»* | Отредактируйте описание в YouTube/VK и нажмите «Повторить» |
| `ERR_VIDEO_PRIVATE` | *«Видео недоступно. Убедитесь, что открыт публичный доступ»* | Измените настройки приватности в соцсети |
| `ERR_INSUFFICIENT_FUNDS` | *«Недостаточно средств на балансе для запуска кампании»* | Пополните баланс в разделе «Финансы» |
| `ERR_CASHOUT_MIN_LIMIT` | *«Минимальная сумма вывода составляет 500 ₽»* | Дождитесь завершения проверки активных роликов |
