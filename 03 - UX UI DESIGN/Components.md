# 🧩 Библиотека компонентов интерфейса (Components Library)

## 1. Базовые атомарные компоненты (Primitives)

1. **Button (Кнопка действия):**
   * Варианты: `Primary` (Зеленый `#10B981` с белым текстом), `Secondary` (Темно-серый `#1E232B` с белой границей), `Danger` (Красный `#EF4444` для отклонения), `Ghost` (без фона).
   * Размеры: `sm` (32px), `md` (40px), `lg` (48px — стандарт для главного CTA в TMA).
2. **Input / Form Field (Поле ввода):**
   * Высота 48px, радиус скругления 10px, фокусная рамка 2px (`--border-strong`), встроенная кнопка очистки и кнопка «Вставить из буфера».
3. **Badge / Chip (Статусный бейдж):**
   * Закругленный тег (радиус 9999px), полупрозрачный фон с ярким цветным текстом. Варианты: `Active`, `Hold`, `Rejected`, `Verified`.
4. **Progress Bar (Индикатор освоения пула):**
   * Высота 4px, скругление 2px, плавный переход ширины заливки (CSS transition 300ms).

---

## 2. Сложные составные организмы (Organisms)

1. **Submission Card (Карточка отправленного ролика):**
   * Превью 16:9 слева (64x36px), название кампании, бейдж просмотров с моноширинными цифрами, таймер холда, выпадающее меню действий.
2. **Campaign Detail Header (Шапка оффера):**
   * Полноэкранный баннер, аватар автора, бейдж проверенного партнера, плашка текущей ставки CPM и оставшегося бюджета.
3. **Dispute Resolution Card (Окно арбитража):**
   * Двухколоночный блок: бриф заказчика слева, сданный ролик и доказательства клиппера справа, кнопки вердикта внизу.
