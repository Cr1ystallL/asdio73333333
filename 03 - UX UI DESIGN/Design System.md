# Дизайн-Система и UI Токены (Design System)

Документ описывает структуру UI токенов, систему отступов, радиусов и теней платформы Konveer.

---

## 1. Токены сетки и пространственная шкала (Spacing Scale)

Интерфейс построен на 4-пиксельной сетке:
- `space-1`: 4px — микро-отступы между иконкой и лейблом.
- `space-2`: 8px — внутренние отступы бейджей и мелких кнопок.
- `space-3`: 12px — расстояние между элементами формы.
- `space-4`: 16px — стандартный базовый паддинг карточки в мобильном интерфейсе.
- `space-6`: 24px — расстояние между смысловыми блоками.
- `space-8`: 32px — вертикальные отступы десктопных секций.

---

## 2. Радиусы скругления (Border Radius)
- `rounded-sm`: 4px — чекбоксы, мелкие теги.
- `rounded-md`: 8px — поля ввода (inputs), кнопки.
- `rounded-lg`: 12px — карточки кампаний, диалоговые окна.
- `rounded-xl`: 16px — контейнеры мобильного Mini App.
- `rounded-full`: 9999px — аватары, бейджи статусов.

---

## 3. Тени и глубина (Elevation & Shadows)
- В темной теме тени заменяются едва заметными внутренними или внешними границами (`border border-white/[0.08]`).
- В светлой теме используются мягкие рассеянные тени:
  - `shadow-sm`: `0 1px 2px 0 rgb(0 0 0 / 0.05)`
  - `shadow-md`: `0 4px 6px -1px rgb(0 0 0 / 0.08)`
  - `shadow-xl`: `0 20px 25px -5px rgb(0 0 0 / 0.1)` (для модальных окон).
