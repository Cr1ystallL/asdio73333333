## 2. Экран модерации входящих роликов (Review Table)

* **Таблица сабмитов:**
  * Инлайн-плеер: клик на превью открывает всплывающее модальное окно с оригинальным шортсом.
  * Столбец «Проверка ТЗ»: авто-индикаторы зелеными галочками (хэштег найден, ссылка в описании есть).
  * Быстрые действия в один клик:
    * `[ Принять ]` (принудительно досрочно одобрить).
    * `[ Отклонить... ]` (открывает список мотивированных причин отказа с авто-возвратом средств в пул).
