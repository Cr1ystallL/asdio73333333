# 👁️ Доступность (A11y) и визуальные референсы

## 1. Стандарты доступности (WCAG 2.1 AA)
* **Коэффициент контрастности текста:** Не менее **4.5:1** для основного текста (14px) и не менее **3.0:1** для крупных заголовков (24px+) на темном фоне.
* **Минимальные зоны нажатия (Touch Targets):** На смартфонах любая интерактивная кнопка имеет физический размер не менее **44x44 CSS пикселей**, даже если визуальная иконка 20x20px (за счет прозрачных паддингов).
* **Семантическая разметка:** Все элементы форм имеют явные теги `<label>`, кнопки снабжены атрибутами `aria-label`, таблицы аналитики имеют семантические `<th>` и `aria-sort`.
