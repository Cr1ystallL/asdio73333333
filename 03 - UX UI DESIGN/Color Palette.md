# 🎨 Цветовая палитра интерфейса (Color Palette)

## 1. Темная палитра (Dark Theme — По умолчанию для Telegram Mini App)

| Токен | HEX | Назначение | Контрастность (WCAG к фону) |
| :--- | :---: | :--- | :---: |
| `--bg-base` | `#0D0F12` | Основной фон приложения | — |
| `--bg-card` | `#161A20` | Поверхность карточек, списков, модальных окон | — |
| `--bg-card-hover` | `#1E232B` | Состояние наведения / активного нажатия | — |
| `--border-subtle` | `#232932` | Разделители, границы карточек и инпутов | 3.2:1 |
| `--border-strong` | `#374151` | Фокусные границы активных полей ввода | 4.8:1 |
| `--text-primary` | `#F9FAFB` | Главный текст, балансы, заголовки | **16.5:1 (AAA)** |
| `--text-secondary` | `#9CA3AF` | Описания, метаданные, второстепенный текст | **7.2:1 (AAA)** |
| `--text-muted` | `#6B7280` | Плейсхолдеры, отключенные элементы | 4.6:1 (AA) |
| `--accent-money` | `#10B981` | Зеленый акцент денег, баланса, кнопки вывода | **8.1:1 (AAA)** |
| `--accent-brand` | `#4F46E5` | Индиго-акцент бренда, B2B действия | 6.5:1 (AA) |
| `--status-warning` | `#F59E0B` | Холд, внимание, заканчивающийся бюджет | 7.9:1 (AAA) |
| `--status-danger` | `#EF4444` | Ошибки, отклоненные ролики, штрафы | 5.8:1 (AA) |

## 2. Светлая палитра (Light Theme — Для Web-портала рекламодателя)

| Токен | HEX | Назначение |
| :--- | :---: | :--- |
| `--bg-base-light` | `#FFFFFF` | Основной чистый белый фон страниц |
| `--bg-card-light` | `#F8FAFC` | Подложка дашборда и таблиц |
| `--border-light` | `#E2E8F0` | Тонкие границы карточек |
| `--text-primary-light` | `#0F172A` | Глубокий графитовый текст высокой четкости |
| `--text-muted-light` | `#64748B` | Вспомогательный серый текст |
