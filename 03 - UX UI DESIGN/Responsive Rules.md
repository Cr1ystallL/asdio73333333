# 📐 Правила адаптивности и брейкпоинты (Responsive Rules)

## 1. Сетка брейкпоинтов (Tailwind CSS)

| Брейкпоинт | Мин. ширина | Целевые устройства | Поведение интерфейса |
| :--- | :---: | :--- | :--- |
| **`xs` (Mobile TMA)** | 360px | iPhone SE, компактные Android | 1 колонка карточек, скрытие второстепенных тегов |
| **`sm` (Large Mobile)** | 420px | iPhone 14/15 Pro Max, стандартные смартфоны | Полноразмерный мобильный виджет |
| **`md` (Tablet)** | 768px | iPad, планшеты | 2 колонки карточек, переход таббара в боковую панель |
| **`lg` (Desktop Small)** | 1024px | Ноутбуки 13–14 дюймов | Боковой сайдбар развернут, 3 колонки дашборда |
| **`xl` (Desktop Standard)** | 1280px | Мониторы Full HD | Максимальная ширина контейнера 1200px с центрированием |
| **`2xl` (Ultra-wide)** | 1536px | Большие мониторы 2K/4K | Центрирование контента, предотвращение растягивания строк таблицы |

---

## 2. Адаптивные правила поведения таблиц
* На десктопе (`lg`+): полноразмерная таблица из 8 колонок.
* На планшете (`md`): скрытие колонок «Дата сабмита» и «Текущие лайки», доступных при раскрытии строки.
* На мобильном (`<md`): трансформация строки таблицы в автономную вертикальную карточку.
