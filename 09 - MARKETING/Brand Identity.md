# Айдентика и фирменный стиль Konveer (Brand Identity)

## 1. Логотип

- **Знак:** буква `K`, собранная из оранжево-красной ленты (конвейер) и чёрного «рычага» со шкивом-кругом.
- **Надпись:** `onveer` — широкий геометрический гротеск, продолжает знак `K`.
- **Версии файлов** (папка `mediaref/`, PNG с прозрачным фоном):
  - `K_logo.png` / `Konveer_logo.png` — для светлых фонов.
  - `K_logo_light.png` / `Konveer_logo_light.png` — для тёмных фонов (лендинг, Telegram Mini App).

## 2. Палитра (по утверждённому референсу лендинга)

| Роль | Цвет | Применение |
| :--- | :--- | :--- |
| Фон | `#070707` → `#0E0E10` | Основной тёмный фон |
| Поверхность карточек | `#141416` с границей `rgba(255,255,255,0.08)` | Карточки, блоки |
| Акцент (основной) | `#FF5A1F` | Кнопки, ключевые слова, иконки |
| Акцент (градиент) | `#FF7A1A` → `#FF3D00` | Кнопки CTA, свечение |
| Свечение | `rgba(255,90,31,0.35)` | Glow вокруг 3D-объектов и CTA |
| Текст основной | `#FFFFFF` | Заголовки |
| Текст вторичный | `#B8B8BE` | Описания |

## 3. Типографика
- **Заголовки:** Russo One — широкий, рубленый, кириллица.
- **Текст:** Manrope 400–700.

## 4. Визуальный язык
- Тёмный фон + 3D-объекты (телефон, хлопушка, монеты ₽, корона, кошелёк) с оранжевым свечением.
- Оранжевая косая черта `/` перед заголовками секций — фирменный маркер.
