# Архитектура Фронтенда (Frontend Architecture)

Документ описывает структуру клиентских веб-приложений платформы Konveer: адаптивный веб-кабинет для клипперов и аналитический веб-портал для рекламодателей и администраторов.

---

## 1. Технологический стек фронтенда

- **Фреймворк**: **Next.js 15 (App Router)** с поддержкой Server-Side Rendering (SSR) и React Server Components (RSC).
- **Язык**: **TypeScript 5.x**.
- **Стилизация**: **Tailwind CSS v4** + дизайн-система `shadcn/ui` (Radix UI примитивы) с адаптивностью под мобильные экраны и 4K-мониторы.
- **Стейт-менеджмент**: **Zustand** (клиентское состояние) + **TanStack Query v5 (React Query)** для кэширования серверных данных, бесконечной прокрутки офферов и мутаций.
- **Формы и валидация**: **React Hook Form** + **Zod** (мастера создания кампаний, сдача ссылок на ролики, реквизиты выплат).
- **Графика и визуализация данных**: **Recharts** (динамика просмотров, освоение бюджетов, CPM, доходы клиппера).
- **Таблицы данных**: **TanStack Table v8** (реестры роликов, транзакций и кампаний с фильтрацией и сортировкой).
- **Интеграция с Telegram**: Telegram Login Widget (авторизация в веб в 1 клик) + Telegram Bot API (уведомления о статусах модерации и начислениях).

---

## 2. Архитектура монорепозитория (Turborepo)

```
apps/
├── web/               # Единый веб-портал Konveer (Next.js 15)
│   ├── app/(auth)/    # Авторизация (Telegram Login / Email / Телефон)
│   ├── app/(clipper)/ # Кабинет нарезчика (лента офферов, сдача роликов, статистика, кошелек)
│   ├── app/(advert)/  # Кабинет рекламодателя (создание кампаний, аналитика, биллинг)
│   └── app/(admin)/   # Защищенная панель модерации и управления Ledger
packages/
├── ui/                # Общие дизайн-компоненты (shadcn/ui, кнопки, бейджи, модалки, инпуты)
├── api-client/        # Автосгенерированный TypeScript SDK из OpenAPI бэкенда
└── tsconfig/          # Базовые настройки TypeScript
```
